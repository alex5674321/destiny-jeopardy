# Destiny Jeopardy

Aplicación web local para organizar un Jeopardy presencial inspirado en Destiny 2.

## Funciones

- Jugadores o equipos ilimitados con puntuación.
- Categorías y preguntas completamente editables.
- Respuestas ocultas hasta que el presentador las revela.
- Guardado automático en el navegador.
- Exportación e importación de copias en JSON.
- Sin instalación ni dependencias.

## Uso local

Abre **index.html** en cualquier navegador moderno.

## GitHub Pages

Sube estos archivos a un repositorio y activa **Settings → Pages → Deploy from a branch** usando la rama principal y la carpeta raíz.

## Multimedia

Las imágenes de preguntas, avatares y pistas de audio se guardan en el navegador mediante IndexedDB. El reproductor musical no muestra el nombre del archivo. La exportación completa incluye también estos archivos.
